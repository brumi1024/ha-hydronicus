# Hydronicus 1.1.0

The curve number, a timed warm-up, and several lead zones for the heating curve.
Renaming `room_influence.zone` would make this a major release; it ships as 1.1.0 because 1.0.0 was out for only a few hours, and the line below says what to change.

## What changed

- `source.weather_curve.curve_number` binds the number that picks which of the heat pump's own weather curves runs; Hydronicus owns it through the new **Weather curve number** entity and adopts a change made on the heat pump's controller; its `hotter: lower` or `hotter: higher` says which way makes the curve hotter.
- A **Warm-up** switch and the `hydronicus.warm_up` and `hydronicus.end_warm_up` actions raise the heating supply for a bounded time, set by the optional `source.warm_up`; a warm-up that would raise nothing is refused.
- Room influence takes several lead zones: `source.supply.room_influence.zones` lists them, and the coldest one calling for heat leads the heating curve, or the coldest of all while none calls; a Plant file with `room_influence.zone:` must change it to `zones: [...]` before it is imported again.
