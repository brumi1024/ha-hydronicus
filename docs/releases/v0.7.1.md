# Hydronicus 0.7.1

This release stops Hydronicus from stopping a source it takes over.

## Taking over a running source

- Arming a source's request while the source already runs, such as a heat pump its own controller started, no longer turns it off, waits for its minimum off time, and starts it again.
  Hydronicus takes the request as it finds it, the way it already did after a handover: it keeps it on while a zone calls, and releases it as usual when none does.
- Its minimum on time, hold after demand, and starts per hour count from when the request was seen turning on.

Turning **Control equipment** on from Dry run still starts from rest, as before.
