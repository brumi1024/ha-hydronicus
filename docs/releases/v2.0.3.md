# Hydronicus 2.0.3

Home Assistant no longer logs an error from Hydronicus when it stops, nor warnings about the zone thermostats when it starts.

## What changed

- When Home Assistant stops, a Plant with a weather forecast no longer logs `Unable to remove unknown job listener` for its forecast.
  The forecast tried to remove its one-time stop listener after that listener had already fired and removed itself.
- The zone thermostats now provide the temperature names Home Assistant 2026.11 introduced, so it no longer warns at startup that they provide `current_temperature`, `target_temperature` and `_attr_temperature_unit`, which stop working in Home Assistant 2027.11.
  The thermostats show and accept the same temperatures as before, and Home Assistant 2026.9 and 2026.10 keep working.

Every 2.0.2 plant file imports unchanged.
